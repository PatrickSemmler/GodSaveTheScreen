GodSaveTheScreen {{VERSION}}
============================

Screenshot- und Annotationstool fuer Windows / Screenshot and annotation tool for Windows.

DEUTSCH
-------
Start
  GodSaveTheScreen.exe ausfuehren. Eine Installation und ein installiertes .NET sind nicht noetig.
  Das Programm laeuft danach im Infobereich der Taskleiste (Tray). Hotkeys (Standard):
  Strg+Umschalt+1 Rechteck, +2 Fenster, +3 Freiform, +4 Vollbild. F1 oeffnet die Hilfe, Strg+F1 zeigt alle Tastenkuerzel.

Daten
  Standard:  Einstellungen in %APPDATA%\GodSaveTheScreen, Logs und automatische Sicherungen in %LOCALAPPDATA%\GodSaveTheScreen.
  Portabel:  Eine leere Datei "portable.txt" neben die EXE legen. Dann liegen alle Daten im Ordner "data" neben der EXE.
             (Die Datei liegt diesem ZIP bewusst nicht bei.)

SmartScreen
  Die EXE ist nicht signiert. Windows SmartScreen kann deshalb warnen ("Der Computer wurde durch Windows geschuetzt").
  Waehlen Sie "Weitere Informationen" und dann "Trotzdem ausfuehren".

Druck-Taste
  Unter Windows 11 kann die Taste Druck vom System belegt sein. Ausschalten unter
  Einstellungen > Barrierefreiheit > Tastatur > "Schaltflaeche 'Druck' zum Oeffnen der Bildschirmaufnahme verwenden".

Deinstallation
  EXE loeschen. Optional den Datenordner (siehe oben) loeschen. Falls "Mit Windows starten" aktiv war, vorher in den
  Einstellungen ausschalten.

ENGLISH
-------
Start
  Run GodSaveTheScreen.exe. No installation and no installed .NET runtime are required.
  The app keeps running in the notification area (tray). Default hotkeys:
  Ctrl+Shift+1 rectangle, +2 window, +3 freeform, +4 full screen. F1 opens the help, Ctrl+F1 shows all keyboard shortcuts.

Data
  Default:   settings in %APPDATA%\GodSaveTheScreen, logs and automatic backups in %LOCALAPPDATA%\GodSaveTheScreen.
  Portable:  Put an empty file named "portable.txt" next to the EXE. All data is then stored in the "data" folder next to it.
             (The file is intentionally not part of this ZIP.)

SmartScreen
  The EXE is not code-signed, so Windows SmartScreen may warn ("Windows protected your PC").
  Choose "More info" and then "Run anyway".

Print Screen key
  On Windows 11 the Print Screen key may be reserved by the system. Turn it off under
  Settings > Accessibility > Keyboard > "Use the Print screen button to open screen capture".

Uninstall
  Delete the EXE. Optionally delete the data folder (see above). If "Start with Windows" was enabled, turn it off in the
  settings first.
